# Frequently Asked Questions

## Where are my files stored?
WriteMd uses a hybrid vault model. By default, new files created in the app are saved to `~/Documents/WriteMD/` (or your configured vault path). However, you can open any markdown file anywhere on your computer, and it will be edited and saved in place. WriteMd never locks you into a proprietary format.

## Does WriteMd require an internet connection?
No! The core editor is 100% offline. WriteMd does not have accounts or telemetry. Network connections are only used if you configure an AI Assistant and select a cloud provider like OpenAI or Anthropic. 

## How do I configure the AI Assistant?
1. Open Settings (`Ctrl+,`).
2. Navigate to the **AI Assistant Config** section.
3. Select your provider (e.g. OpenAI, Anthropic, or Ollama for local offline AI).
4. Enter your API key (stored securely and locally on your machine).
5. Click **Fetch** to retrieve available models and select one.

## How do I update WriteMd?
WriteMd features a seamless auto-updater. When a new release is available, a "Restart to update" button will appear in the top right corner. 

## Is WriteMd open source?
Yes, WriteMd is open source and free to use.

## How do I customize colors or themes?
WriteMd provides several built-in themes (Dark, Light, Paper, etc.). You can switch between them in Settings -> Appearance. All UI and code syntax colors are tied to your chosen theme.
